# Finance

A personal finance management app for tracking accounts, transactions, transfers, budgets, and recurring bills. Built
with [Laravel](https://laravel.com), [Inertia.js](https://inertiajs.com), and [React](https://react.dev).

## Features

- **Transactions** — track income, expenses, and transfers, with search, sorting, category filtering, and pagination.
- **Transfers** — move money between accounts atomically, keeping account balances in sync.
- **Budgets** — set a spending cap per category and track how much has been spent against it each month.
- **Recurring bills** — create, edit, and delete recurring bills (weekly, monthly, or yearly); a scheduled command
  automatically generates the corresponding transaction and advances the due date. Bills can also be created directly
  from the transaction form by toggling "Save as a recurring bill".
- **Categories & accounts** — manage personal spending categories and financial accounts from Settings.
- **Authentication** — registration, login, password reset, email verification, two-factor authentication (TOTP +
  recovery codes), and passkeys (WebAuthn), powered by [Laravel Fortify](https://laravel.com/docs/fortify).
- **Appearance settings** — light theme.

### Roadmap

- **Overview** — dashboard summarizing balances and recent activity.
- **Pots** — savings goals, visible in the navigation but not implemented yet.

## Tech stack

**Backend**

- PHP 8.3+, Laravel 13
- Inertia Laravel, Laravel Fortify (auth), Laravel Wayfinder (typed routes/actions for the frontend)
- Pest for testing, Pint for formatting, Larastan (PHPStan) for static analysis

**Frontend**

- React 19 with TypeScript
- Inertia.js (React adapter)
- Tailwind CSS v4, Radix UI primitives, Phosphor Icons
- Vite

**Database**

- SQLite by default (configurable via `.env`)

## Requirements

- PHP >= 8.3 with Composer
- Node.js 18+ and npm
- A database supported by Laravel (SQLite is preconfigured; MySQL/PostgreSQL also work)

## Getting started

```bash
git clone <repository-url>
cd finance

composer install
npm install

cp .env.example .env
php artisan key:generate
```

By default the app uses SQLite. Create the database file if it doesn't exist yet:

```bash
touch database/database.sqlite
```

If you prefer MySQL/PostgreSQL, update the `DB_*` variables in `.env` accordingly.

Run migrations and build the frontend:

```bash
php artisan migrate
npm run build
```

Alternatively, `composer run setup` performs the install/env/key/migrate/build steps above in one go (useful for a
first-time setup).

Serve the app with `php artisan serve`, or via [Laravel Herd](https://herd.laravel.com) if you have it installed — no
extra step needed, Herd serves the project directory automatically.

### Development

Run the backend server, queue listener, and Vite dev server together:

```bash
composer run dev
```

Frontend route helpers (`resources/js/actions`, `resources/js/routes`) are generated automatically by the Wayfinder Vite
plugin while `npm run dev` or `npm run build` is running. If you ever need to regenerate them manually:

```bash
php artisan wayfinder:generate
```

### Scheduled tasks

Recurring bills are turned into transactions by the `bills:generate` Artisan command, scheduled to run daily. In
development, run the scheduler with:

```bash
php artisan schedule:work
```

In production, add the standard Laravel cron entry:

```
* * * * * php /path/to/artisan schedule:run >> /dev/null 2>&1
```

## Testing & quality checks

```bash
# Full backend test suite (also runs Pint and PHPStan checks first)
composer test

# Run a specific test file/filter
php artisan test --compact --filter=RecurringBillControllerTest

# PHP formatting
composer lint          # fix
composer lint:check    # check only

# PHP static analysis
composer types:check

# Frontend linting, formatting, and type checking
npm run lint            # fix
npm run lint:check      # check only
npm run format           # fix
npm run format:check     # check only
npm run types:check      # tsc --noEmit
```

## Project structure

```
app/
  Console/Commands/     # e.g. bills:generate
  Http/Controllers/
  Http/Requests/        # form request validation
  Models/
  Policies/
  Services/             # domain logic (e.g. recurring bill date calculations)
database/
  migrations/
  factories/
resources/js/
  pages/                # Inertia page components
  components/           # shared UI + feature components (incl. modals)
  actions/, routes/      # generated by Wayfinder (gitignored)
  types/                 # shared TypeScript types
tests/
  Feature/
  Unit/
  Browser/               # Pest browser tests
```
